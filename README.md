# Living Particle Artwork

**Real-Time Computer Vision × Generative Art × Interactive Particle Simulation**

Living Particle Artwork is an interactive generative art project that transforms a real-world environment into a dynamic, glowing particle-based digital world.

Using real-time webcam input and computer vision, the project detects and segments a person, converting their live silhouette into thousands of glowing particles that become part of a virtual nighttime landscape.

The environment features a procedurally generated tree and grass field, both continuously animated through simulated wind physics.

## Features

- **Real-Time Human Segmentation:** Detects and extracts a person from live webcam input.
- **Particle-Based Human Rendering:** Transforms the detected human silhouette into a glowing particle representation.
- **Procedural Tree Generation:** Creates a particle-based tree with branches and a detailed canopy.
- **Wind Simulation:** Animates grass blades, branches and tree particles with natural wind-like movement.
- **Interactive Artwork:** Reflects real-world body movements and poses in the virtual environment.
- **Generative Particle Effects:** Uses glowing blue and violet particles, shimmer effects and atmospheric rendering.
- **Live Webcam Integration:** Processes camera input continuously without prerecorded footage.

## Technology Stack

- Python
- OpenCV
- MediaPipe
- NumPy
- Pygame / OpenGL

## How It Works

1. Webcam input captures the real-world environment.
2. Computer vision processes the camera feed and segments the person.
3. The extracted silhouette is converted into a particle representation.
4. A procedurally generated virtual environment renders the tree and grass.
5. Wind simulation continuously animates the environment.
6. The human particle silhouette is integrated into the scene and updated as the person moves.

## Visual Concept

The project combines real-time computer vision with procedural animation to create an interactive digital landscape.

The visual environment uses:
